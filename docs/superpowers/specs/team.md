# 偶遇导航（Serendipity Navigation）团队分工

## 成员与角色
- 成员 A：前端负责人
- 成员 B：后端负责人
- 成员 C：项目/演示/文档负责人

## 核心职责

### 成员 A：前端负责人
- 负责网页版页面、交互、状态展示。
- 负责高德地图 JS API 接入、路线与 POI 标注。
- 负责 Loading / Error / Empty / 结果页体验。
- 负责前端测试与打包输出验证。

### 成员 B：后端负责人
- 负责 FastAPI 服务、接口定义与数据清洗。
- 负责高德 Web 服务调用：地理编码、路径规划、POI 搜索。
- 负责绕行计算、规则打分、推荐结果生成。
- 负责后端单测、接口测试与错误降级。

### 成员 C：项目/演示/文档负责人
- 负责需求对齐、里程碑、演示脚本与现场演示。
- 负责更新计划文档、测试清单、README。
- 负责打包/发布/演示环境整理。
- 负责收集现场反馈并排序缺陷。

## 协作方式
- 接口先定字段，再并行开发。
- 后端先提供 Mock 接口，前端先接。
- 每天对齐阻塞项，演示前统一收口。

- 是否保留 LLM 叙事并统一 fallback 文案标准。
- 现场演示网络环境与备用展示方案。
