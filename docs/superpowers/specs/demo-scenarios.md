# 现场演示脚本（大连 3 组场景）

> 用于在无高德 Key / 弱网环境下，也能稳定复现“偶遇导航”核心体验。

## 一键启动

1. 启动后端：`cd backend && uvicorn app.main:app --reload`
2. 启动前端：`cd webapp && npm run dev`
3. 浏览器打开：`http://localhost:5173`

## 接口验证

```bash
curl -X POST http://localhost:8000/api/route/recommend \
  -H "Content-Type: application/json" \
  -d '{"origin":"121.6068,38.9180","destination":"121.5854,38.9325","mode":"+15"}'
```

## 演示场景

### 场景 1：大连理工大学 -> 星海广场
- 模式：`+15`
- 预期：额外 15 分钟左右，可能出现餐饮 / 海边散步道亮点。
- 话术：从校园出发，绕到海边前多走一段，看看有没有值得停的小店。

### 场景 2：东港音乐喷泉广场 -> 老虎滩海洋公园
- 模式：`roam`
- 预期：探索评分最高，沿东港到老虎滩方向展示海边路线与景点亮点。
- 话术：不赶时间，想走一条更有意思的海边路线。

### 场景 3：西安路 -> 傅家庄
- 模式：`+5`
- 预期：轻微绕行，可能出现西安路小吃 / 傅家庄林荫段亮点。
- 话术：只接受 5 分钟以内的意外，但希望顺路更有意思。

## 场景输入参数

## 离线降级说明

- 无高德 Key 时，后端会返回内置演示数据。
- 无 LLM 时，后端会返回默认叙事。
- 前端可离线访问已构建产物 `webapp/dist`。
